Krypty

La messagerie qui ne sait pas que vous existez.

Ouvrir l'applicationCode source

Pourquoi

Une messagerie classique connaît votre numéro, votre liste de contacts, l'heure de chaque message et souvent leur contenu. Krypty part du principe inverse : aucune machine n'a besoin de savoir que vous existez pour que vos messages arrivent.

Pas de compte

Votre identité est une paire de clés créée sur votre appareil. Pas de numéro, pas de mail, pas de mot de passe.

Pas d'annuaire

On ne vous « trouve » pas. Vous invitez quelqu'un avec un lien à usage unique, envoyé par le canal de votre choix.

Pas de serveur central

Quand deux personnes sont en ligne, elles se parlent en direct. Sinon, le message chiffré attend dans un « répondeur » que n'importe qui peut héberger.

Le cercle est le relais

Votre répondeur peut tourner chez vous, chez un ami, sur un Raspberry. Le réseau, c'est vos contacts.

Comment ça marche

  Alice                          Répondeur (aveugle)                        Bob
  ─────                          ───────────────────                        ───
  lien #i/… ─── n'importe quel canal (SMS, mail, papier) ───────────────────▶ colle
                                                                             │ vérifie la signature
                                                                             │ numéro de sécurité
                        ◀── intro chiffrée dans la boîte d'accueil ──────────┘
  crée le contact
  intro‑ack chiffré ──▶ boîte de Bob ───────────────────────────────────────▶ contact prêt

  message ✓ ─────────▶ boîte de Bob (blob opaque, id aléatoire) ───────────▶ lu → ack → effacé ✓✓
  ⚡ tunnel direct (WebRTC) ◀════════════════════════════════════════════════▶ fichiers, sans limite

Le répondeur ne voit que des identifiants de boîtes aléatoires et des blobs chiffrés. Il ne sait ni qui écrit, ni qui lit, ni ce qui est écrit. Il efface chaque blob à la lecture, ou après 15 jours.

Chiffrement

QuoiComment
IdentitéX25519 (échange de clés) + Ed25519 (signature), générées par le navigateur (WebCrypto), jamais exportées sauf dans votre sauvegarde chiffrée.
Clé de conversationHKDF‑SHA256(X25519(moi, lui)) → AES‑256‑GCM. Dérivée localement des deux côtés, jamais transmise.
InvitationClés publiques + boîte d'accueil, signées Ed25519. Un lien modifié est refusé.
Lecture des boîtesChaque boîte a sa propre clé Ed25519 ; le répondeur exige une signature d'un nonce pour la lire. Poster ne demande rien.
Numéro de sécurité60 chiffres dérivés des deux clés publiques — identique des deux côtés si personne n'est au milieu.
SauvegardeAES‑256‑GCM, clé dérivée d'une phrase secrète (PBKDF2 300 000 itérations).

Utiliser

Dans le navigateur

  1. Ouvrir l'application, choisir un nom et une couleur. Un tag (Nyx#7F3A) est dérivé de votre clé.
  2. ＋ Inviter → copier le lien → l'envoyer. L'autre le colle dans Rejoindre, compare le numéro de sécurité, accepte.
  3. Écrire. ⏳ en attente d'un répondeur · ✓ déposé · ✓✓ lu · ⚡ passé en direct.

Héberger un répondeur (optionnel, ~100 lignes de Python)

pip install websockets cryptography
python relay.py 8765

Puis dans l'app : Réglages → Répondeurs → ws://localhost:8765. Vos contacts sont prévenus automatiquement et déposeront aussi chez vous. Depuis une page en https://, seuls localhost et les wss:// sont acceptés par le navigateur (voir DEPLOY.md pour un tunnel gratuit).

Limites connues (honnêtement)

  • Une identité = un appareil, sauf si vous exportez une sauvegarde et la restaurez ailleurs. Deux appareils actifs en même temps se partagent les messages sans se synchroniser : le premier qui lit efface.
  • Pas de forward secrecy pour l'instant : la clé de paire est statique. Une clé privée volée déchiffre l'historique capturé.
  • Le cercle porte : vos deux contacts les plus récents gardent vos messages chiffrés quand vous êtes absent, automatiquement. Ils ne peuvent pas les lire. Un porteur hostile peut au pire jeter un message : c'est pour ça qu'il y en a deux.
  • Il faut un point de rendez-vous pour que deux navigateurs se trouvent la première fois (ou après un redémarrage sans contact commun en ligne). Il ne voit que des boîtes anonymes et des blobs chiffrés.
  • Fichiers : uniquement en direct (tunnel). Hors ligne, seuls les textes attendent.
  • Pas de groupes dans cette version.
  • Perdre l'appareil sans sauvegarde = perdre l'identité. Les contacts devront vous ré‑inviter.
